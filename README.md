# Alt Data Forge

Public work from [Alt Data Forge](https://altdataforge.com): notes, worked examples and small tools about
research data that only uses what was public at the time.

Most research data records what a value is. Far less of it records **when anyone could have known it**. A
backtest or a model evaluation that sees a filing, a revised figure or a reassigned ticker before it was public
looks better than it is. The work here is about dating, matching and checking public records so that does not
happen.

## What is here

| Folder | What it holds |
|---|---|
| [`notes/`](notes/) | Short write-ups on point-in-time data problems, each with the check that shows the problem |
| [`examples/`](examples/) | Small, runnable examples on public data |
