# Notes

Short write-ups on point-in-time data problems. Each note states the problem, shows it on public data, and
gives a check you can rerun.

Planned:

- **When a ticker changes hands** - how one company's history leaks into another's, and how permanent
  identifiers stop it.
- **Filed, accepted, public: when did the market know?** - why the moment a fact became public is the only date
  a backtest may use.
- **From 78 GB to 10 GB on one desktop** - processing a 189-million-row table without running out of memory.
